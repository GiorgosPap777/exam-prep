# Exam Prep

Μικρή εφαρμογή για εξάσκηση σε ερωτήσεις από τα σχολικά βιβλία, φτιαγμένη για κινητό:
μία ερώτηση τη φορά, μεγάλα κουμπιά, άμεση διόρθωση, σκορ και επανάληψη στα λάθη.
Δουλεύει offline και εγκαθίσταται στην αρχική οθόνη του κινητού.

Υποστηρίζει **πολλά μαθήματα** — ένα αρχείο ανά μάθημα κάτω από το `data/`.

## Τοπική εκτέλεση

```bash
python3 -m http.server 8000
```

Άνοιγμα στο `http://localhost:8000`. (Το άνοιγμα του `index.html` με διπλό κλικ
δεν δουλεύει: το `file://` δεν επιτρέπει `fetch` των αρχείων του `data/`.)

## Δημοσίευση

Είναι στατικά αρχεία — ανεβάζεις τον φάκελο όπως είναι σε GitHub Pages ή σε
οποιονδήποτε static host. Από το κινητό: άνοιγμα της σελίδας → «Προσθήκη στην
αρχική οθόνη».

## Τι υποστηρίζει

- **Πολλαπλής επιλογής** — ένα υποερώτημα ανά κάρτα
- **Σωστό / Λάθος** — μία πρόταση ανά κάρτα, δύο μεγάλα κουμπιά
- **Αντιστοίχιση** — όλη η άσκηση σε μία κάρτα, ώστε να λύνεται συγκριτικά

Η πρόοδος και η μισοτελειωμένη συνεδρία αποθηκεύονται στο `localStorage`, οπότε
μπορείς να κλείσεις την εφαρμογή στη μέση και να συνεχίσεις μετά.

## Επιλογή ύλης

Τρεις οθόνες, από το γενικό στο ειδικό:

| Οθόνη | Τι δείχνει | Το κουμπί έναρξης παίζει |
|---|---|---|
| Αρχική | κάρτες μαθημάτων + συνολική πρόοδος | — διάλεξε πρώτα μάθημα (μόνο «Συνέχεια») |
| Μάθημα | κεφάλαια με checkbox και πρόοδο | μόνο μέσα σε αυτό το μάθημα |
| Κεφάλαιο | chips ασκήσεων | μόνο μέσα σε αυτό το κεφάλαιο |

Μια συνεδρία είναι **πάντα μέσα σε ένα μάθημα** — δεν ανακατεύονται ερωτήσεις από
διαφορετικά μαθήματα.

Υπάρχει **μία** αποθηκευμένη επιλογή: ποιες ασκήσεις είναι μέσα. Το checkbox του
κεφαλαίου είναι παράγωγο — δείχνει ✓ / – / κενό (όλες / μερικές / καμία) και με ένα
πάτημα βάζει ή βγάζει ολόκληρο το κεφάλαιο. Στις «Ρυθμίσεις» υπάρχουν επιπλέον τα
καθολικά φίλτρα: τύπος ερώτησης, «μόνο όσες έχω λάθος», «μόνο αναπάντητες».

## Εγκατάσταση στο κινητό

Την πρώτη φορά που ανοίγει, η εφαρμογή δείχνει μια οθόνη εγκατάστασης:

- **Android / Chrome / Edge** — κουμπί «Εγκατάσταση εφαρμογής» που ανοίγει απευθείας
  τον native διάλογο του browser (μέσω του `beforeinstallprompt`).
- **iPhone / iPad** — η Apple δεν επιτρέπει προγραμματιστικό prompt, οπότε εμφανίζονται
  δύο βήματα με εικονίδια: *Κοινή χρήση* → *Πρόσθεση στην αρχική οθόνη*.
- **Οτιδήποτε άλλο** — οδηγία να χρησιμοποιηθεί το μενού του browser.

Από κάτω υπάρχει πάντα «Συνέχεια στον browser» για όποιον δεν θέλει να την εγκαταστήσει·
η επιλογή θυμάται, και η εγκατάσταση ξαναβρίσκεται από τον σύνδεσμο «Εγκατάσταση» στην
αρχική. Όταν η εφαρμογή τρέχει ήδη εγκατεστημένη, η οθόνη δεν εμφανίζεται καθόλου.

**Χρειάζεται HTTPS.** Εκτός από το `localhost`, ο browser εγκαθιστά PWA μόνο πάνω από
HTTPS — βάλε ένα reverse proxy με πιστοποιητικό μπροστά από το container.

## Docker

```bash
docker run -d -p 8080:80 --name exam-prep giorgospap777/exam-prep:latest
```

και άνοιγμα στο `http://localhost:8080`.

Η εικόνα είναι `nginx:alpine` με μόνο τα στατικά αρχεία (~75 MB, `linux/amd64`).
Το nginx στέλνει `Cache-Control: no-cache` για το `index.html`, το `sw.js`, το
`data/`, το CSS και το JS, ώστε ένα καινούριο deploy να φτάνει στις ήδη
εγκατεστημένες συσκευές αντί να κολλάει πίσω από το HTTP cache.

Build τοπικά:

```bash
docker build -t exam-prep .
```

## Η τράπεζα ερωτήσεων

```
data/index.json        ο κατάλογος των μαθημάτων
data/chemistry.json    ένα αρχείο ανά μάθημα
data/physics.json
```

Έλεγχος ακεραιότητας — όλα τα μαθήματα ή ένα μόνο αρχείο:

```bash
node tools/validate-questions.mjs
```

Για την προσθήκη νέου μαθήματος ή νέων ερωτήσεων από φωτογραφίες, δες το `CLAUDE.md`.

# Χημεία — Εξάσκηση

Μικρή εφαρμογή για εξάσκηση σε ερωτήσεις χημείας από το σχολικό βιβλίο, φτιαγμένη
για κινητό: μία ερώτηση τη φορά, μεγάλα κουμπιά, άμεση διόρθωση, σκορ και επανάληψη
στα λάθη. Δουλεύει offline και εγκαθίσταται στην αρχική οθόνη του κινητού.

## Τοπική εκτέλεση

```bash
python3 -m http.server 8000
```

Άνοιγμα στο `http://localhost:8000`. (Το άνοιγμα του `index.html` με διπλό κλικ
δεν δουλεύει: το `file://` δεν επιτρέπει `fetch` του `questions.json`.)

## Δημοσίευση

Είναι στατικά αρχεία — ανεβάζεις τον φάκελο όπως είναι σε GitHub Pages ή σε
οποιονδήποτε static host. Από το κινητό: άνοιγμα της σελίδας → «Προσθήκη στην
αρχική οθόνη».

## Τι υποστηρίζει

- **Πολλαπλής επιλογής** — ένα υποερώτημα ανά κάρτα
- **Σωστό / Λάθος** — μία πρόταση ανά κάρτα, δύο μεγάλα κουμπιά
- **Αντιστοίχιση** — ένα στοιχείο της στήλης Α ανά κάρτα, επιλογή από τη στήλη Β

Φίλτρα ανά κεφάλαιο, άσκηση και τύπο· «μόνο όσες έχω λάθος» και «μόνο αναπάντητες».
Η πρόοδος και η μισοτελειωμένη συνεδρία αποθηκεύονται στο `localStorage`, οπότε
μπορείς να κλείσεις την εφαρμογή στη μέση και να συνεχίσεις μετά.

## Docker

```bash
docker run -d -p 8080:80 --name chemistry-app giorgospap777/chemistry-app:latest
```

και άνοιγμα στο `http://localhost:8080`.

Η εικόνα είναι `nginx:alpine` με μόνο τα στατικά αρχεία (~75 MB, `linux/amd64`).
Το nginx στέλνει `Cache-Control: no-cache` για το `index.html`, το `sw.js`, το
`questions.json`, το CSS και το JS, ώστε ένα καινούριο deploy να φτάνει στις ήδη
εγκατεστημένες συσκευές αντί να κολλάει πίσω από το HTTP cache.

Build τοπικά:

```bash
docker build -t chemistry-app .
```
